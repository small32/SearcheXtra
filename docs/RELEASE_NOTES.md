# SearcheXtra 2.0.5

[简体中文](#简体中文) · [English](#english)

## 简体中文

为 Windows 和 macOS 新增超级拖拽功能，并完善书签栏的图标显示和鼠标操作。

### 新增与优化

- **超级拖拽**：拖动链接、选中文字或图片，即可执行搜索、复制、翻译、打开标签页、下载图片及以图搜图等操作。
- **自定义拖拽规则**：支持四方向或八方向、组合键、触发距离及释放区域设置，可添加、编辑和重置规则，修改后立即生效。
- **拖拽设置与提示**：支持方向和操作提示、网站例外，以及规则配置的 JSON 导入、导出，两端可以共用配置。
- **右键快捷入口**：网页右键菜单支持启用或停用超级拖拽、排除当前网站、查看规则和打开设置。
- **在线服务确认**：首次使用搜索、翻译或以图搜图时，提示所用服务并请求确认；输入框、地图和编辑器等区域保留原有拖动行为。
- **书签菜单切换**：打开书签栏文件夹后，将鼠标移到其他文件夹即可自动切换下拉菜单。
- 将“书签栏文件夹图标”和“书签显示网站图标”开关集中放到设置中的“书签管理器”页面。

### 修复

- 修复书签栏及文件夹下拉菜单中的网站图标无法正常显示或更新的问题。
- 修复书签鼠标中键打开行为：中键始终在后台新建标签页，左键继续遵循用户设置，适用于书签栏和文件夹下拉菜单。

## English

Adds Super Drag on Windows and macOS and improves bookmark icons and mouse interactions.

### New and Improved

- **Super Drag:** Drag links, selected text, or images to search, copy, translate, open tabs, download images, or perform an image search.
- **Custom drag rules:** Configure four-way or eight-way directions, modifier keys, drag distance, and drop regions. Add, edit, or reset rules, with changes taking effect immediately.
- **Settings and feedback:** Configure direction and action hints, website exclusions, and JSON configuration import and export. Configurations can be shared between both platforms.
- **Context menu shortcuts:** Enable or disable Super Drag, exclude the current website, view rules, or open settings from the webpage context menu.
- **Online service confirmation:** Search, translation, and image search require confirmation before first use. Input fields, maps, and editors retain their existing drag behavior.
- **Bookmark menu switching:** After opening a bookmark folder, hover over another folder to switch its dropdown automatically.
- Moved the bookmark folder icon and website icon controls to the Bookmark Manager section in Settings.

### Fixes

- Fixed missing or delayed website icons in the bookmark bar and folder dropdown menus.
- Fixed middle-click behavior for bookmarks: middle-click always opens a background tab, while left-click follows the configured preference. This applies to both the bookmark bar and folder dropdown menus.
