# SearcheXtra 2.2.6

## 简体中文

同步上游 macOS 更新，改善浏览、扩展兼容及运行性能。

- 使用上游浮动地址栏，修复新建标签与分屏时的输入焦点，完善书签、历史补全及网站图标显示。
- 修复触控板导航后的白边和页面偏移，恢复返回页面时的滚动位置，并改善画中画与全屏视频操作。
- 改善扩展侧边栏、链接预览和小窗口中的扩展兼容，保留 MV2/MV3 用户脚本支持。
- 加快图片复制、扩展查询及翻译启动，完善 Arc 空间与图标导入。
- 支持批量关闭选中的标签并一次恢复，关闭内置管理页面后返回原标签。
- 修复无痕权限隔离、下载覆盖、书签导入、图标缓存及翻译会话清理问题。

## English

Sync upstream macOS updates and improve browsing, extension compatibility and performance.

- Use the upstream floating address field, fix new-tab and Split View focus, and improve bookmark/history completion and site icons.
- Fix blank strips and page offsets after swipe navigation, restore scroll positions on return, and improve picture-in-picture and full-screen video controls.
- Improve extension side panels and extension support in link previews and small windows, retaining MV2/MV3 user-script compatibility.
- Speed up image copying, extension queries and translation startup, and improve Arc space and icon import.
- Close selected tabs as a batch and restore them together; return to the previous tab after closing built-in management pages.
- Fix private permission isolation, download replacement, bookmark import, favicon caching and translation-session cleanup.
