# SearcheXtra 2.0.2

[简体中文](#简体中文) · [English](#english)

## 简体中文

统一 macOS 和 Windows 的扩展管理方式，并改善 Windows 的扩展安装和使用体验。

### 新增与优化

- 独立扩展管理：两端设置页提供“扩展管理”入口，采用卡片式界面，支持搜索、启用或停用、查看详情和移除扩展。
- 标题栏固定扩展：支持将常用扩展图标固定在扩展按钮旁，点击即可打开，固定状态在重启后保留。

---

## English

Unifies extension management on macOS and Windows and improves extension installation and use on Windows.

### New and improved

- Dedicated extension manager: Settings on both platforms provide an Extension Management entry with a card-based interface for searching, enabling or disabling, viewing details, and removing extensions.
- Pinned title-bar extensions: Pin frequently used extension icons next to the extensions button and click to open them. Pinning preferences persist across restarts.
